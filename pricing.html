How the money actually arrives

Create a Stripe account, make a $4.99/month Payment Link, and paste that URL into STRIPE_CLIMBER_LINK in js/game.js. Send the success redirect to play.html?pass=1. That turns the pass on in this browser.

A static site cannot safely prove a payment by itself. When money starts coming in, add Stripe webhooks on a small backend so a pass cannot be faked with a URL. Until then, treat the preview code in the README as owner-only.

Ads are the second stream, not the first. Google AdSense usually wants a live site, original pages, and a privacy policy. Put ads only on the free climb so the pass feels worth paying for.
